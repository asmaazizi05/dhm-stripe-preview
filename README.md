# Discover Hidden Morocco — Édition Thème Stripe

Une refonte complète du site **Discover Hidden Morocco** inspirée du design system mondialement reconnu de [Stripe.com](https://stripe.com).

---

## 🎨 Ce qui a été appliqué (L'ADN Stripe)

1. **Fluid Mesh Gradient Hero & Canvas 60fps** :
   - Fond dynamique animé en temps réel aux couleurs du Maroc (Indigo Majorelle `#4F46E5`, Ocre Terracotta `#E15A3E`, Safran Doré `#F59E0B`, Rose Couchant `#EC4899`).
   - Blobs morphologiques organiques avec flou gaussien et accélération matérielle.

2. **Carte 3D Interactive & Télémétrie d'Itinéraire (Style Stripe Dashboard)** :
   - Carte flottante avec perspective 3D, barres de statut, timeline de parcours étape par étape (Marrakech → Dades → Merzouga → Fès) et badges d'inclusions VIP.
   - Bouton de réservation instantanée direct vers WhatsApp (+212 660-082066).

3. **Navigateur d'Expéditions à Onglets Interactifs (Style Stripe Product Suite)** :
   - Commutation fluide entre les catégories phares :
     - 🏜️ **Sahara Desert Expeditions** (Glamping luxe & dunes Erg Chebbi)
     - 🕌 **Imperial Medinas & Riads** (Marrakech, Fès, Chefchaouen)
     - ⛰️ **High Atlas & Valleys** (Vallée d'Imlil, Toubkal, Ourika)
     - 🌊 **Atlantic Coastal Hideaways** (Essaouira & océan)

4. **Simulateur d'Itinéraire en Temps Réel (Style Stripe Code/Demo Playground)** :
   - Choisissez la ville de départ, la durée (3, 5, 7, 10+ jours) et le style de voyage.
   - Calcul instantané de la feuille de route personnalisée avec génération automatique d'un message WhatsApp pré-rempli pour devis en direct.

5. **Grille Bento Moderne (Bento Grid)** :
   - Présentation asymétrique des 4 piliers d'excellence (Flotte Mercedes VIP privée, Guides Berbères certifiés, Riads & Glamping 5 étoiles, Conciergerie 24/7).

6. **Témoignages & Avis Clients Style Stripe Customer Stories** :
   - Avis réels vérifiés avec notation 5 étoiles, avatars stylisés et mentions d'itinéraires.

7. **Mega Footer Stripe & Badges de Confiance** :
   - Bandeau Travellers' Choice 2026, agrément officiel du Ministère du Tourisme, coordonnées complètes de Marrakech et liens sociaux.

## 🌐 Déploiement sur GitHub & Hostinger

### 1. Sur GitHub (GitHub Pages) :
1. Créez un nouveau dépôt ou utilisez votre dépôt existant.
2. Copiez l'ensemble des fichiers du dossier `discover_hidden_morocco_stripe`.
3. Poussez (`git push`) sur votre branche `main`.
4. Activez GitHub Pages dans les paramètres du dépôt (`Settings > Pages > Deploy from branch /root`).

### 2. Sur Hostinger (Hébergement Web) :
1. Connectez-vous à votre panneau de contrôle Hostinger (hPanel).
2. Rendez-vous dans **Gestionnaire de fichiers (File Manager)**.
3. Ouvrez le dossier `public_html`.
4. Transférez le contenu de `discover_hidden_morocco_stripe` dans `public_html`.
5. Votre site est immédiatement en ligne avec le nouveau design Stripe !
